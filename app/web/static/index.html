Reliability principles

Fail closed. Compliance rules run before any model, so a blocked lead never reaches scoring.
Know when not to decide. Predictions inside the uncertainty band go to a human.
Independent verification. A separate critic checks every draft. The generator never grades itself.
Bounded loops. Revisions are capped at 3. After that the lead escalates, so it can never loop forever.
Explainable. Every triage decision carries reason codes, and every decision is written to the graph.
Honest evaluation. The seed labels were checked for signal first (AUC 0.50), and that finding is reported.
PII minimised. Contact details are masked at the context boundary, before traces or logs.
